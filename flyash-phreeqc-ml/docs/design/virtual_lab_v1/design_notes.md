## Scientific Safety Requirements

* Simulation is not validation.
* Validation requires measured data.
* XRD advisory is tentative, not confirmed phase identification.
* ICP processes supplied/measured data; it does not fabricate measurements.
* ML requires a trained model.
* Literature evidence retains provenance and human-review status.
* Every result must show its honest data/output type.
