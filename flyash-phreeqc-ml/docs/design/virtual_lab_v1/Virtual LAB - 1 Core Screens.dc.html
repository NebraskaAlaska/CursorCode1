Assumptions and design reasoning
· Epistemic honesty is the design system. Every value on every screen carries a data-status badge (measured / simulation / ML / advisory / literature / demo). Missing data is rendered as visibly missing — never auto-filled.
· All numbers shown are placeholders badged SYNTHETIC DEMO. No real scientific output is depicted; result areas show layout, not science.
· Industry design system re-grounded dark: steel-blue accent, Barlow Condensed headings, square corners, hairline borders, blueprint registration marks. A light "projector mode" is a token swap.
· Desktop-first at 1440 px; narrow-width adaptations in Part 4. Every layout maps to Streamlit primitives (sidebar, columns, bordered containers, dataframes, expanders) — see the handoff spec in Part 5.
