# Simulation Lab Project WPI

The Materials Research Assistant runs reviewed chemistry calculations, processes instrument data and compares predictions with laboratory measurements.

- [Leaching progress](flyash-phreeqc-ml/docs/research/leaching-progress.md) explains the experiments, verification methods, results for individual materials and the remaining independent scandium test.
- [Project progress](flyash-phreeqc-ml/docs/research/project-progress.md) covers the ChatGPT pilot, calcite benchmarks and the status of the research workflows.
- [Materials Research Assistant](flyash-phreeqc-ml/README.md) contains the application setup and technical documentation.
- [ChatGPT pilot download and installation guide](https://github.com/NebraskaAlaska/CursorCode1/releases/tag/simulation-lab-wpi-chatgpt-v0.2.0) are available with the 0.2.0 release.
